# AI Data Classification

## Description
This project demonstrates a simple AI classification model using the Iris dataset.

## Features
- Load Iris dataset
- Split data into training and testing
- Train a Decision Tree Classifier
- Predict test data
- Calculate model accuracy

## Technologies Used
- Python
- Scikit-learn
- Pandas
- NumPy

## Installation
pip install -r requirements.txt

## How to Run
```bash
python main.py
```

## Sample Output
```text
Accuracy: 96.7%
Prediction:
Iris-setosa
```
